## 5. 交互实现（任务拆解 §6 异常分支全覆盖）

- **接口失败**：统一错误提示（「接口不可用，请确认 8091 服务已启动」）+ 重试按钮，不白屏。
- **超时**：AbortController 10s，归入统一错误提示。
- **空库**：code=2 透出后端引导文案；各视图空态「暂无数据」；对账 0 差异「三方一致」。
- **刷新防抖**：刷新期间按钮禁用（`refreshing` 状态）；刷新失败保留旧数据。
- **一键刷新（2026-11-12 增强）**：侧栏底部「刷新数据」按钮 → `POST /api/collect` 服务端重采；采集中按钮禁用并显示「采集中…」，失败在按钮下方红字提示；成功后用返回的 `collected_at/projects` 更新侧栏健康状态，并递增 `refreshTick` 触发 `RouterView` 重挂载，各视图 `onMounted` 重新拉取最新数据。
- **超长文本**：台账 detail/根因列截断 + `title` 悬浮全文。
- **可聚焦**：导航/按钮 `:focus-visible` 外圈；侧边栏当前项灰 pill。

## 6. 运行说明

```bash
cd 05_代码/frontend
npm install          # 依赖安装（55 packages）
npm run dev          # 开发态 http://127.0.0.1:5184（需 8091 后端在跑）

# 演示态：重启后端后浏览器直接打开 http://127.0.0.1:8091/（单进程整站）
```

数据更新：侧栏「刷新数据」按钮一键触发后端重采（`POST /api/collect`，幂等重建），成功后自动重拉；也可在命令行重跑后端 `python collect.py`，前端 F5 刷新。侧栏「数据截至 HH:MM」读 `/health.collected_at`，采集后即变（ISS-S6-005，第 6 步新增；一键按钮为 2026-11-12 增强）。
