## 3. 核心实现要点

- **噪声规则（D-07/§3）**：HTML 注释跳过（含多行）、空单元格→NULL、步骤号归一（`第5.5步`/`step6.5`/`👤 R-1`→`5.5`/`6.5`/`R-1`；`10` 与 `10.0` 保留原文不浮点化避免撞车）、状态词归一（E4 6 值枚举 + ✅/⏭️ 前缀剥离 + 括号尾注进 note）。
- **幂等重建（D-09）**：`db.rebuild()` DROP 8 表 2 视图→CREATE→executemany；连跑两次全表 count 不变（已实测）。
- **gate_reds 交叉提取（§4）**：失败日志 triggered_rule（R5/R8/R9/R12…）+ 度量台账 gate_reds>0 双源。
- **逃逸矩阵（E1 降级口径）**：`found_step`（来源阶段，全量）× `source_step_inferred`（归属「第X步」文本推断，可空）；仅可推断项目计数，覆盖率 N/M 同步返回（当前 13/120）。
- **空库兜底（D-17）**：库文件缺失或 projects 0 行 → 全部 `/api/*` 返回 `code=2` + 引导提示；`/health` 恒 200。
- **仅回环监听（D-29）**：uvicorn 绑定 `127.0.0.1:8091`（netstat 实测仅回环 LISTEN）。

## 4. 接口定义（GET 只读聚合 + POST `/api/collect` 触发重采，统一响应包 `{"code":0,"msg":"ok","data":{...}}`）

| 接口 | 说明 | 关键返回 | 错误码 |
|---|---|---|---|
| GET `/health` | 探活 + 数据新鲜度 | `data.status/db_initialized/collected_at/projects`（`collected_at` = 最近一次 collect 的 ran_at；无 collect_runs 记录时为 `null`） | 0 |
| GET `/api/projects` | 项目+完成度+步骤矩阵（热力图源） | `projects[].steps[{step_no,status,note}]`、`completion` | 0/2/500 |
| GET `/api/steps` | 返工 TOP（降序）+ 每项目明细 | `top[{step_no,fail_count,projects}]` | 0/2/500 |
| GET `/api/failures` | 根因/类别/项目分布 + 最近 20 条 | `by_category/by_root_cause/by_project/recent` | 0/2/500 |
| GET `/api/metrics` | 返工率/报红趋势/逃逸矩阵+覆盖率/跨项目对比 | 每块带 `coverage{scope,source,note}`（D-25 三级口径：全量/增量/推断） | 0/2/500 |
| GET `/api/reconcile` | 3 类勾稽 + 未解析清单 | `classes{A_产物存在性,B_条数勾稽,C_状态词闭环}` + `unresolved[]` | 0/2/500 |
| POST `/api/collect` | 一键重采：服务端复用 `collect.run_collection` 幂等重建 metrics.db（无请求体；root 自动探测、db 取 .env，不接收外部路径参数） | `data.total/parsed_ok/ratio/anomalies/counts/collected_at/projects`；进程内锁防并发重入 | 0/500 |
| GET `/docs` `/openapi.json` | OpenAPI 契约（6.5 契约源、5B 输入） | paths=7（5 聚合 + /health + /api/collect） | — |

错误码：0 成功 / 1 参数（预留） / 2 库未初始化 / 500 内部错（HTTP 恒 200，语义在包内）。鉴权：无（internal-tool + 回环，8.5 复核项）。

## 8. 使用说明（运行时数据更新）

数据更新 = 重跑采集（幂等重建，源文件唯一事实源）；服务无需重启（WAL 并发安全）。三种触发方式：

1. **看板一键刷新**：侧栏「刷新数据」按钮 → `POST /api/collect` 服务端重采，成功后前端自动重拉各视图（推荐）。
2. **命令行**：`python collect.py`；Windows 双击 `collect_now.bat`（= `.venv\Scripts\python.exe collect.py`，失败暂停显示原因）。
3. **直接调接口**：`POST http://127.0.0.1:8091/api/collect`（无请求体；进程内锁防并发重入，采集中重复点击返回 500「采集正在进行中」）。

看板侧栏显示「数据截至 HH:MM」（来自 `/health.collected_at`），即最近一次采集时间——两次采集之间的源文件改动不会自动反映，看到时间没变就说明该重跑了。
